# Privacy — prototype status

The implemented scene service decodes/re-encodes an authenticated image, uses it transiently and does not create media files or memory records. Mock does not contact Meta. Meta mode sends a normalized image to Meta only after server configuration and an explicit synthetic-fixture flag. Do not submit personal media during the current testing phase.

Free-credit billing currently warns of product-improvement use. Read [privacy architecture](PRIVACY_ARCHITECTURE.md) before enabling real-user data. This file does not promise zero provider retention.

Planned controls before user testing: clear camera/microphone indicators, contextual consent, pause, explicit memory-save confirmation, delete memory/evidence, explicit retention and Care scope/revocation. Those controls are not implemented yet. AINGEL is an assistive prototype; it does not diagnose, prescribe, monitor emergencies or certify safe navigation.
