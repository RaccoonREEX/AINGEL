# Three-minute demo — planned

The official participant guide requires three minutes; the original 90-second idea is superseded. This script is a plan, not a working-feature claim.

| Time | Evidence to show |
|---|---|
| 0:00–0:20 | One person with combined seeing/hearing/memory needs; independence and one adaptive profile. |
| 0:20–0:55 | Real scene description, then SAM object localization; show server/model provenance and accessible output. |
| 0:55–1:30 | Explicitly save observed glasses with timestamp/evidence, retrieve it, then ask about an unrecorded object and show no-evidence response. |
| 1:30–2:00 | Live Voice captions and device TTS/AAC; clearly distinguish STT from speech generation. |
| 2:00–2:25 | Authorized Care message/routine grounds a response; show permission boundary. |
| 2:25–2:45 | Architecture, Meta cooperation, English/Spanish switch, measured evaluation and limits. |
| 2:45–3:00 | Label Halo future concept; closing product statement. |

Only include features actually passing acceptance tests. Synthetic fixtures must be identified. Do not film billing, credentials or personal media. Verify public video and repository links while signed out. Rehearse provider failure handling and APK installation before recording.
